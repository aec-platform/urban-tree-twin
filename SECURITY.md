# Security policy

## Supported versions

The `main` branch is the only supported version while the product is pre-1.0.

## Reporting a vulnerability

Please email `security@urban-tree-twin.example` with:

- A description of the issue
- A reproducer (curl, request body, or repo link)
- The impact you observed and any data exposure

Do not file public GitHub issues for security reports.

We aim to acknowledge within 48 hours and ship a patched release within 14 days
for high-severity issues.
